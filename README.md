# Starbucks Beverage Analytics Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze Starbucks beverage data and generate insights into nutritional values and beverage categories.

## Dashboard Preview
![Dashboard Overview](Screenshots/dashboard-overview.png)

## Key Features
- **KPI Analysis:** Total beverage count, average sugar, calories, and caffeine.
- **Category Analysis:** Comparative analysis of different beverage categories.
- **Caffeine Analysis:** Identification of caffeine-rich beverages.
- **Calorie Trends:** Exploration of calorie distribution across beverages.
- **Interactive Filters:** Dynamic filtering for better data exploration.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Files
- `Starbucks-Beverage-Analytics.pbix` – Power BI dashboard file.
- `Screenshots/` – Dashboard screenshots.

Download the `.pbix` file and open it using Microsoft Power BI Desktop.
